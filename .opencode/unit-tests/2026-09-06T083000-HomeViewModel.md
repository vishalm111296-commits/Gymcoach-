# Unit Test Record: HomeViewModel.kt

## Target File
`app/src/main/kotlin/com/gymcoach/app/presentation/home/HomeViewModel.kt`

## Change Summary
Fixed critical bug in `plannedWeeklySets()` function where the entire day's total set count was broadcast to every target muscle instead of being attributed per-exercise.

## Bug Description
**Before**: If a training day had 3 exercises (2+2+2=6 total sets) targeting "Back, Chest", BOTH Back AND Chest got credited 6 sets. Back exercises might only account for 4 sets, and Chest for 2.

**After**: Each exercise's set count is attributed to its specific `muscleGroup` via an `exerciseId → muscleGroup` mapping loaded from `ExerciseRepository`.

## Changes Made
1. Injected `ExerciseRepository` into `HomeViewModel` constructor
2. Added `_exerciseMuscleMap: MutableStateFlow<Map<Long, String>>` to hold exercise→muscle mapping
3. Added init block to collect exercises and build the mapping
4. Combined `_exerciseMuscleMap` into the existing flow chain
5. Updated `buildUiState()` to accept `exerciseMuscleMap` parameter
6. Updated `plannedWeeklySets()` to iterate per-exercise and look up muscleGroup
