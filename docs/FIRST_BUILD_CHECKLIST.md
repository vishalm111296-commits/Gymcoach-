# First Build Checklist

Complete every item below before attempting to obtain the first APK.

- [ ] I have an active internet connection on my Android phone.
- [ ] I have registered a free GitHub account.
- [ ] I have created an empty repository on GitHub named `GymCoach`.
- [ ] I have uploaded the entire GymCoach project (including `.github` and `gradle` folders) to the new repository.
- [ ] I have verified the upload on the GitHub website.
- [ ] I have navigated to the **Actions** tab in the repository.
- [ ] I have confirmed the "Android CI/CD Pipeline" workflow is running or completed.
- [ ] The workflow run displays a green checkmark indicating success.
- [ ] I have located the **Artifacts** section at the bottom of the workflow run page.
- [ ] I have downloaded the `gymcoach-debug-apk` artifact.
- [ ] I have extracted the downloaded `.zip` file on my phone.
- [ ] I have enabled "Install unknown apps" for my file manager or browser.
- [ ] I have installed the `app-debug.apk` file.
- [ ] I have successfully launched the GymCoach app on my device.
